Center Cross Library System, you can see it [https://centercrosslibrary.org](Running here!).

The Center Cross Library System is a library management system made and developed for Center Cross Academy in St. Louis MO.
it features book, checkout, student, class, teacher, and author management. It uses Bulma CSS and has a consistent style and theme.

the system also allows for backups, user authentication, automatic book over finding, book information auto filling, and advanced searching. 

Run `npm run dev` for local development. This starts the app without authentication and uses a local development user. Do not expose this development server to a network.
Run `npm start` to start the app with Google authentication enabled.
